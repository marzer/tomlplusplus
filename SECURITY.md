# Security policy

## Reporting a vulnerability

Please report security problems privately, with **Report a vulnerability** on the repository's
[Security tab](https://github.com/marzer/tomlplusplus/security). Don't open a public issue for them.

Include the toml++ version or commit hash, the input that triggers the problem and what happens.

## Supported versions

Only the latest release is supported. Fixes go into `master` and ship in the next release.
